# Xiaoxuan's World

A personal space for notes and discoveries, built with [Docusaurus](https://docusaurus.io/).

## Development

Requires Node.js 22 or newer.

```sh
npm ci
npm start
```

Run `npm run build` to build the site and `npm run serve` to preview it. To enable the repository's checks, [install pre-commit](https://pre-commit.com/#installation) and run `pre-commit install`.

## Deployment

The GitHub Actions workflow deploys changes pushed to `master`. Set the GitHub Pages source to **GitHub Actions** in the repository settings.
